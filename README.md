# 🚀 International Space Station

A responsive website about the **International Space Station (ISS)**, inspired by NASA's visual style and content.

## 🛠️ Technologies

- HTML5
- Tailwind CSS
- CSS Grid
- Flexbox
- CSS Position

## ✨ Features

- Responsive design for Desktop, Tablet, and Mobile
- Responsive image gallery
- ISS information and specifications
- Modern NASA-inspired UI
- Grid and Flexbox layouts
- Positioned elements for advanced layouts

## 📱 Responsive Design

The website is optimized for:

- 💻 Desktop
- 📱 Tablet
- 📱 Mobile

Different layouts, grid structures, spacing, and image sizes are used for each screen size.

## 📚 Resources

NASA's **International Space Station** page was used as a reference for the information and images.

[NASA — International Space Station](https://www.nasa.gov/international-space-station?utm_source=chatgpt.com)

## 🎯 Goal

This project was created to practice **HTML, Tailwind CSS, responsive design, CSS Grid, Flexbox, and Position**.
